# ISA-ARC Workspace Specification Collection

This draft collection combines the ISA-ARC workspace conventions with the ISA-XLSX and WR-XLSX metadata formats.

| Specification | Document version | Scope |
| --- | --- | --- |
| [ISA-ARC Workspace](./ISA-ARC-Workspace.md) | 3.0.0-draft.2 | Workspace structure and content. |
| [ISA-XLSX](./ISA-XLSX.md) | 3.0.0-draft.1 | Experimental metadata and shared XLSX conventions. |
| [WR-XLSX](./WR-XLSX.md) | 1.0.0-draft.1 | Workflow and run metadata extending ISA-XLSX. |

The directory version identifies the workspace collection. Each specification retains its own document version. ISA-ARC Workspace 3.0.0-draft.2 references ISA-XLSX 3.0.0-draft.1 and WR-XLSX 1.0.0-draft.1; WR-XLSX extends ISA-XLSX 3.0.0-draft.1.

Relative links between these documents stay within this collection so their dependencies can be read together.
