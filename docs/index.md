# ISA-ARC Workspace

ISA-ARC is DataPLANT's domain-specific application of the [Annotated Research Context (ARC)](https://arc-rdm.org/) for workspaces supporting ARC research data management (ARC RDM).

The [specification collection](./specifications/index.md) defines the workspace structure and the metadata formats used for experimental and computational provenance:

- [ISA-ARC Workspace](./specifications/ISA-ARC-Workspace.md) defines the workspace structure and content.
- [ISA-XLSX](./specifications/ISA-XLSX.md) defines experimental metadata and shared XLSX conventions.
- [WR-XLSX](./specifications/WR-XLSX.md) extends ISA-XLSX for workflow and run metadata.

The current editions are drafts. Their individual versions and dependencies are listed in the specification collection.
